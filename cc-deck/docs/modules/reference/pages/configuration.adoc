= Configuration Reference

== Manifest (`build.yaml`)

The `build.yaml` manifest is the central configuration file for cc-deck builds.
It lives in the setup directory (`.cc-deck/setup/build.yaml`).

=== `probe_tools`

An optional list of additional tools to probe for when inspecting a base image.
Each entry has a `name` and an optional `version` constraint.

[source,yaml]
----
probe_tools:
  - name: rustc
    version: "1.78"
  - name: cmake
----

When `probe_tools` is defined, these entries are merged with the default tool set (approximately 30 tools from the cc-deck base image).
Manifest entries override defaults by name.
Tools not in the default set are added to the probe.

=== `agents`

A list of AI coding agents to include in the build.
Each agent maps to one or more OpenShell provider profiles.
When no `agents` field is present, the build defaults to `claude`.

[source,yaml]
----
agents:
  - claude
  - opencode
----

Supported agents: `claude`, `opencode`, `codex`.

=== `tools`

A list of tools to install in the image.
For OpenShell targets, each tool also maps to a provider profile that allows access to the tool's package registry.

[source,yaml]
----
tools:
  - name: python
  - name: go
  - name: node
  - name: rust
----

=== `credentials`

Credential declarations for OpenShell workspaces.
Each entry maps to a provider profile at workspace creation time.
No secrets are stored in the manifest.

[source,yaml]
----
credentials:
  - type: claude-vertex
  - type: github
----

Supported types: `claude`, `claude-vertex`, `github`, `gitlab`, `openai`, `nvidia`, `generic`.

== Profile Manifest (`profiles.yaml`)

For OpenShell targets, the build embeds a `profiles.yaml` at `/etc/openshell/profiles.yaml` in the OCI image.
This file lists the provider profiles that cc-deck creates at workspace creation time.

[source,yaml]
----
profiles:
  - anthropic
  - claude-agent
  - github
  - gitlab
  - python
mcp:
  - name: my-mcp-server
    endpoint: "mcp.example.com:9090"
custom_domains:
  - custom.example.com
  - internal.corp
agent_binaries:
  - /usr/bin/claude
----

`profiles`::
A sorted, deduplicated list of OpenShell provider profile IDs.
These are resolved from the manifest's `agents`, `tools`, and `credentials` fields via a static mapping table.

`mcp`::
MCP server entries with endpoints in `host:port` format.
At workspace creation time, cc-deck imports an ephemeral profile containing these endpoints.
Entries without an endpoint are excluded.

`custom_domains`::
User-defined domains from `network.allowed_domains` and `network.allowed_domains_per_agent`.
At workspace creation time, cc-deck imports an ephemeral profile with these domains as network endpoints (port 443, HTTPS).

`agent_binaries`::
Binary paths for agent executables.
Used in ephemeral MCP profiles to restrict which binaries can access MCP endpoints.

== Cache Files

=== `probe-cache.json`

Location: `<setup-dir>/probe-cache.json`

A JSON file that caches the results of base image probes.
Entries are keyed by image reference and invalidated when the image digest changes.

[source,json]
----
{
  "version": 1,
  "entries": {
    "registry.fedoraproject.org/fedora:41": {
      "image_ref": "registry.fedoraproject.org/fedora:41",
      "image_digest": "sha256:abc123...",
      "os": { "id": "fedora", "name": "Fedora Linux 41" },
      "package_manager": "dnf",
      "tools": { ... }
    }
  }
}
----

The cache is automatically managed by `cc-deck build probe` and the build skill.
Use `--no-cache` to bypass it for a fresh probe.
Delete the file to clear all cached results.
