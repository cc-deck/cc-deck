# Implementation Plan: Credential Transport Abstraction

**Branch**: `079-credential-transport` | **Date**: 2026-07-08 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/079-credential-transport/spec.md`

## Summary

Migrate all credential detection, resolution, and validation from hardcoded profile maps (`KnownProviderProfiles` in openshell, `BuildCredentialSet`/`detectAuthMode` in ssh) to the agent-declared `CredentialSpec` model through the shared `internal/credential` package. Transport functions (OpenShell SDK calls, SSH file upload) remain in their workspace-specific packages but switch from reading legacy maps to accepting `ResolvedCredentials`.

## Research Findings

### What Already Works

The `internal/credential` package already has:
- `Detect(specs)` / `DetectAll()`: Scans host env against agent-declared specs
- `Resolve(spec)`: Produces `ResolvedCredentials` with env vars, file creds, unset vars
- `MergeCredentials(modes)`: Combines multiple detected modes with conflict detection
- `Validate(spec)` / `ValidateAll(modes)`: Checks required credentials are present
- `InjectContainer()`: Podman secret creation and mount generation
- `InjectSSH(ctx, SSHClient, ResolvedCredentials)`: Writes credentials to remote host via SSH (env vars, file upload, unset vars). Already tested. `SSHClient` interface requires `Run()` and `Upload()` methods, which `*ssh.Client` satisfies.
- `InjectOpenShell(ctx, OpenShellClient, sandboxID, ResolvedCredentials)`: Uploads credentials to OpenShell sandbox (env vars, file upload, unset vars). Already tested. `OpenShellClient` interface requires `ExecRun()` and `FileUpload()` methods.
- `InjectK8s(spec, ResolvedCredentials)`: Generates K8s Secret/ConfigMap data for credential injection.

### What Needs Migration

1. **OpenShell credential resolution** (`ws/openshell.go`): Currently builds `[]openshell.CredentialInput` from the manifest, passes to `openshell.ResolveCredentials()` which iterates `KnownProviderProfiles`. Must switch to: get agent from workspace definition, call `credential.Detect(agent.CredentialSpecs())`, then `credential.Resolve()` for the selected mode. The OpenShell path has two distinct concerns:
   - **Provider creation** (lines 311-337): Creates OpenShell SDK providers via `Providers().Ensure()`. This is OpenShell-specific and requires mapping `ResolvedCredentials` to the SDK's `Provider` type with `Credentials` and `Type` fields. The `claude-vertex` special case maps to OpenShell's native `google-cloud` provider type.
   - **Post-start injection** (lines 373-386): Currently uses `openshell.UploadFileCredential()` and `openshell.InjectEnvVars()`. Replace with `credential.InjectOpenShell()` which already handles both. Requires a thin adapter to wrap `v1.ClientInterface` to satisfy `credential.OpenShellClient`.

2. **SSH credential fallback removal** (`ws/ssh.go`): The primary path (lines 194-201) already uses `credential.DetectAll()` + `credential.MergeCredentials()` + `credential.InjectSSH()`. The legacy `ssh.BuildCredentialSet()` is only a fallback in the `else` branch (lines 202-211). Remove the fallback branch entirely. The `DetectAll()` path covers all registered agents; if it returns empty, there are genuinely no credentials to inject.

3. **SSH credential refresh** (`cmd/ws.go:1821`): The `ws credential-refresh` command still calls `sshPkg.BuildCredentialSet()` + `sshPkg.WriteCredentialFile()`. Migrate to `credential.DetectAll()` + `credential.MergeCredentials()` + `credential.InjectSSH()`.

### Migration Pattern

For each caller:
1. Determine the agent (from workspace definition or default "claude")
2. Get the agent's `CredentialSpecs()` via `agent.Get(agentName)`
3. Detect available modes: `credential.Detect(specs)`
4. Select the appropriate mode (from workspace `auth_mode` field or auto-select by priority)
5. Resolve: `credential.Resolve(selectedSpec)`
6. Pass `ResolvedCredentials` to the appropriate `credential.Inject*()` transport function

### Current State of Each Path

| Path | Primary resolution | Transport | Legacy fallback |
|------|-------------------|-----------|-----------------|
| SSH (`ws/ssh.go`) | `credential.DetectAll()` + `InjectSSH()` | `credential.InjectSSH()` | `ssh.BuildCredentialSet()` + `ssh.WriteCredentialFile()` in else branch |
| SSH refresh (`cmd/ws.go`) | None | None | `ssh.BuildCredentialSet()` + `ssh.WriteCredentialFile()` only |
| OpenShell (`ws/openshell.go`) | None | `openshell.InjectEnvVars()` + `UploadFileCredential()` | `openshell.ResolveCredentials()` only path |
| Podman/Compose | `credential.DetectAll()` | `credential.InjectContainer()` | None (already migrated) |
| K8s | Own Secret/ConfigMap path | `credential.InjectK8s()` | None (does not use deprecated functions) |

### Non-Goals

- No changes to `internal/agent` package or `CredentialSpec` types
- No changes to `internal/credential` package functions (they already work)
- No new CLI commands or flags
- No changes to the Podman/Compose credential path (it already uses `credential.InjectContainer`)

## Implementation Approach

### Phase 1: OpenShell Migration

Migrate `ws/openshell.go` from `openshell.ResolveCredentials()` to `credential.Detect()` + `credential.Resolve()`. For provider creation, map `ResolvedCredentials` to the OpenShell SDK `Provider` type. For post-start injection, replace `openshell.InjectEnvVars()` and `openshell.UploadFileCredential()` with `credential.InjectOpenShell()` (requires a thin adapter wrapping `v1.ClientInterface` to satisfy `credential.OpenShellClient`). Remove all deprecated functions and types from `openshell/credentials.go`. Update tests.

### Phase 2: SSH Migration

Remove the fallback branch in `ws/ssh.go` (lines 202-211) that calls `ssh.BuildCredentialSet()`. The primary path already uses `credential.InjectSSH()`. Migrate `cmd/ws.go` credential-refresh to use `credential.DetectAll()` + `credential.MergeCredentials()` + `credential.InjectSSH()`. Remove `BuildCredentialSet()`, `detectAuthMode()`, `WriteCredentialFile()`, and `CopyCredentialFile()` from `ssh/credentials.go`. Update tests.

### Phase 3: Cleanup and Verification

Confirm zero references to legacy functions in production code. Verify SC-004 (credential package test coverage is sufficient). Run `make verify`.
